# سلالة الجريمة — CRIME BLOODLINE

لعبة عالم مفتوح واقعية تدور أحداثها بين **1980 و2010**، مبنية باستخدام **Unreal Engine 5 (C++ & Blueprints)** مع رؤية لتجربة متعددة المنصات (**PC، Android، iOS**) وبنية خوادم مستمرة.

## أبرز ملامح اللعبة
- **خريطتان متباينتان:**
  - **روسيا:** أجواء باردة، ثلوج، أمطار، وضباب، مع مدن وحركة شوارع نابضة بالحياة.
  - **صحراء الربع الخالي:** حرارة نهار مرتفعة، برودة ليل، وعواصف ترابية تختبر قدرة البقاء والتحمل.
- **واقعية البقاء والمحاكاة:** الجوع، العطش، التعب، النوم، الملابس وتأثير الطقس، العمل، العقارات، والتنقل.
- **العصابات والسلطة:** رتب، ولاء، صراعات، تسليم القيادة مؤقتاً للنائب عند اعتقال القائد، نظام الخلافة، ومهام الإنقاذ.
- **القانون والعدالة:** ذكاء اصطناعي للشرطة، جمع الأدلة، المحاكم، الدفاع، الاستئناف، وحياة السجن.
- **الاقتصاد والإعلام:** تغير الأسعار حسب العرض والطلب والأحداث، شبكات الجواسيس، الراديو، والصحف.

## الشخصيات الابتدائية
- **القاتل المأجور:** بنية عضلية ثقيلة (200 سم / 115 كجم) وأسلوب حاد ومباشر.
- **لينا (العميلة):** بنية رشيقة ورياضية (172 سم / 61 كجم) تركز على الحركة والسرعة والمناورة.
- **أعضاء العصابات:** مسار تصاعدي للرتب والسمعة داخل التنظيمات.
